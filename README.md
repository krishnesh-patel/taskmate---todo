# TaskMate - To-Do List Web App

TaskMate is a simple responsive To-Do List web application.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clear completed tasks
- Saves tasks using browser localStorage
- Responsive and simple interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## How to Run
Open `index.html` in a web browser.
